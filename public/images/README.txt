Photos and Custom Logo
======================

Custom Logo
-----------
To use your own logo instead of the default horseshoe icon, place a file named one of:

  logo.png
  logo.svg
  logo.webp
  logo.jpg
  logo.jpeg

inside this folder (public/images/). It will automatically replace the default icon
in the header and footer across the site, and will not appear in the /photos gallery.

Homepage Hero Photo
-------------------
  hero.jpg        Main photo at the top of the homepage (portrait, roughly 5:6)

Photos Page (/photos)
---------------------
Any .jpg, .jpeg, .png, .webp, or .gif image files placed in this folder (other than
logo.*) automatically appear on the /photos gallery page.

Tips: use real photos taken at events or lessons (with permission if guests are
visible), daylight, horses and ponies at eye level. Around 1600px wide is plenty.
